# 🌿 Dr. Skin: Neuro-Symbolic AI Skincare Recommendation System

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1GWVOriU5YzAkkyXXVtgNbL59xiLd_ptA)
[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![Framework](https://img.shields.io/badge/Streamlit-FF4B4B.svg)](https://streamlit.io/)

A state-of-the-art **Neuro-Symbolic Artificial Intelligence** healthcare consultation system that combines **Knowledge Graphs**, **Graph Attention Networks (GAT)**, and **Large Language Models (LangGraph & Gemini)** to deliver precise, explainable, and personalized skincare advice.

---

## 🚀 Key Features
- **Knowledge Graph Representation:** Built with NetworkX & PyVis to map skin types, symptoms, active ingredients, and skincare products.
- **Graph Representation Learning:** Uses **GAT (Graph Attention Networks)** to learn multi-hop entity embeddings.
- **Multi-Agent Conversational Pipeline:** Powered by **LangGraph** orchestrating specialized medical agents (Triage Agent & Pharmacist Agent).
- **Interactive Web App:** Real-time patient interaction built using **Streamlit**.

---

## 🛠️ Tech Stack
- **Deep Learning & Graph Networks:** PyTorch, PyTorch Geometric
- **LLM & Agent Orchestration:** LangGraph, LangChain, Google Gemini API
- **Data & Knowledge Representation:** NetworkX, PyVis, Pandas
- **Deployment & UI:** Streamlit, Cloudflare Tunnels
